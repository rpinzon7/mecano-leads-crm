# CRM Mecano V6.31.4 — Campo visual ampliado en tareas

Mejora visual sobre V6.31.3.

## Cambios

- Se amplió el alto útil del contenedor con scroll de tareas.
- Se compactaron ligeramente las tarjetas de tareas para permitir ver más información de la siguiente tarea.
- Se redujo el espacio vertical del bloque de historial de alertas sin perder trazabilidad.
- Se mantuvieron los botones de correo, WhatsApp, editar, completar y eliminar.
- No requiere SQL nuevo.

## Objetivo

Mejorar la lectura del panel de tareas cuando una tarea vencida tiene historial de alertas y ocupa demasiado espacio visual.
