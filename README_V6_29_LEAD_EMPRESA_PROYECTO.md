# V6.29 - Lead asociado con empresa y proyecto

Cambio aplicado:

- En el módulo **Mis tareas y recordatorios**, el campo **Lead asociado** ahora muestra:
  - `Empresa — Proyecto`
- Si el lead no tiene proyecto, muestra:
  - `Empresa — Sin proyecto`
- En la tarjeta de tarea también se muestra el lead con empresa y proyecto.
- No requiere cambios adicionales en Supabase.

Build validado con `npm run build`.
