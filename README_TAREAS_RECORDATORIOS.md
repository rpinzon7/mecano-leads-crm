# CRM Mecano V6.26 - Tareas y Recordatorios

Cambios incluidos:
- Nuevo módulo independiente: Mis tareas y recordatorios.
- Cada usuario ve solo sus tareas usando auth.uid().
- Tareas con vencidas, hoy, próximas y completadas.
- Crear, editar, completar y eliminar tareas.
- Asociar tareas a leads existentes.
- Desde la edición de un lead se puede crear una tarea relacionada.

Antes de usar:
1. En Supabase, abre SQL Editor.
2. Ejecuta el archivo SUPABASE_TAREAS_RECORDATORIOS.sql.
3. Sube el proyecto a GitHub/Vercel o ejecútalo localmente con npm install y npm run dev.

Validado:
- npm run build ejecutado correctamente.
