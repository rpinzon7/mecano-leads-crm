# CRM Mecano V6.30.1 — Mejora visual de filtros de tareas

Ajuste visual sobre V6.30 para que el buscador y filtros avanzados del módulo de tareas no se vean apretados.

## Cambios

- Se reorganizó el módulo de tareas en dos columnas principales:
  - Columna izquierda: listas y formulario de creación/edición.
  - Columna derecha: panel de tareas con más ancho útil.
- El buscador queda en una fila propia, más grande y legible.
- Los filtros de prioridad, tipo de tarea y lead asociado quedan en una segunda fila.
- Se redujo el texto del botón de limpieza a “Limpiar”.
- Se agregó encabezado “Búsqueda y filtros”.
- Se mantiene la misma lógica funcional de V6.30.

## Base

Partida desde V6.30 — Buscador y filtros avanzados en tareas.

## Base de datos

No requiere cambios en Supabase ni SQL adicional.
