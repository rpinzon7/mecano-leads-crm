# CRM Mecano V6.32.3 — Calendario visual de tareas

## Base

Esta versión parte de V6.32.2 Campo visual + orden básico, conservando las mejoras probadas:

- Administrador global de tareas.
- Botones Correo responsable y WhatsApp responsable en tareas pendientes.
- WhatsApp Web con mensaje prellenado.
- Historial de alertas y trazabilidad.
- Campo visual ampliado de tareas.
- Orden básico por prioridad operativa.

## Nueva mejora

Se agrega una vista adicional de calendario dentro de Mis tareas y recordatorios.

### Incluye

- Botón para cambiar entre Lista y Calendario.
- Vista por Día, Semana y Mes.
- Navegación Anterior / Hoy / Siguiente.
- Tareas agrupadas por fecha límite.
- Tareas sin fecha en bloque separado.
- Clic en tarea del calendario para abrirla en el panel de edición.
- Respeta filtros activos de estado, lista, prioridad, tipo, lead y responsable.

## Importante

No requiere SQL nuevo.
No cambia la estructura de Supabase.
No modifica la lógica de envío por WhatsApp/correo.
