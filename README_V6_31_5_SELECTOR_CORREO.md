# CRM Mecano V6.31.5 — Selector de correo para alertas

Mejora sobre V6.31.4.

## Cambios

- Al usar **Correo responsable**, el CRM permite escoger dónde abrir el correo:
  1. Outlook / aplicación predeterminada del equipo.
  2. Gmail web.
  3. Outlook web.
  4. Copiar asunto y mensaje para pegar en GoDaddy Webmail u otro correo.
- Mantiene la trazabilidad limpia en el bloque **Historial de alertas**.
- No requiere SQL nuevo.

## Nota

Para GoDaddy Webmail se recomienda usar **Copiar asunto y mensaje**, porque no todos los webmail aceptan enlaces de redacción con campos prellenados.
